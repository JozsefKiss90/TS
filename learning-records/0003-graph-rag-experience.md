# Prior knowledge: knowledge graphs and Graph RAG

The user builds and uses knowledge graphs and Graph RAG systems (largely Python-side). Phase 2 does not need to teach retrieval concepts — it needs to teach *exposing* an existing capability through typed MCP tools with provenance-bearing evidence. Guard one predictable confusion: their graph fluency will tempt them to merge knowledge, workflow, and trace graphs into one schema; the mission keeps these separate.
