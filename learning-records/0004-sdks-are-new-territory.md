# Starting point: SDKs are new territory

The user explicitly asked for SDK literacy in Phase 0 — they have consumed APIs through vibe-coded glue but have not deliberately studied what an SDK is, what it abstracts, or how to read one. This sets the Phase 0 floor: begin at raw HTTP vs SDK anatomy (lesson 0001), and treat every SDK feature (auth resolution, retries, typed errors, streaming, cancellation) as teachable, not assumed.

**Implications:** the ordinary model-client SDK must be understood before the Claude Agent SDK is ever introduced (Phase 5); "the SDK is not magic" is the recurring test.
